# ⚖️ YurIIst (ЮрИИст) — Telegram AI Legal Assistant
AI-ассистент, предоставляющий быстрые ответы по законодательству РФ (кодексы, ФЗ, ППВС) без необходимости ручного поиска по сотням страниц. Проект построен на базе **DeepSeek V4 Flash** и **Telegram Bot API**.
> **⚠️ Antiscope:** Бот НЕ предоставляет профессиональные адвокатские консультации, НЕ заменяет живого юриста и НЕ предназначен для использования в качестве представительства в суде.
> 
## 🛠 Технологический стек
 * **Язык:** Python 3.13
 * **Фреймворк:** python-telegram-bot (v22+)
 * **База данных:** SQLite (с использованием полнотекстового поиска **FTS5** и режима WAL). База включает 7 связанных таблиц.
 * **LLM API:** OpenCode Zen, DeepSeek V4 Flash Free
 * **Сетевые запросы:** httpx
 * **Инфраструктура:** Разработан с поддержкой легковесного деплоя на ARM-архитектурах.
## 🏗 Архитектура и безопасность (Production-Ready)
Проект разрабатывался под строгим контролем ИИ-агента с использованием методологии pipeline.md, включающей блокирующие этапы аудита безопасности.
**Ключевые инженерные решения:**
 * **Защита от уязвимостей:** Реализована защита от IDOR (строгая фильтрация сессий по user_id). Внедрена SSRF-защита в модуле web_fetch с блокировкой обращений к private IP и localhost. SQL-инъекции исключены за счет параметризованных запросов.
 * **Rate Limiting & Anti-Abuse:** Настроены лимиты на вызовы LLM (10 запросов/минута на пользователя) и внешние API.
 * **Защита от Prompt Injection:** Внедрена санитизация ввода (обрезка до 4096 символов), фильтрация спецсимволов и жесткие ограничения системного промпта.
 * **Телеметрия:** Собственная система продуктовой аналитики через SQLite (трекинг сессий, платежей, лимитов).
## 🧪 Тестирование (Quality Assurance)
Проект покрыт автоматическими тестами с использованием pytest.
 * Написано и успешно проходит **60+ e2e и unit-тестов**.
 * Покрытие включает модули: payments (16 тестов), session (13 тестов), tools (10 тестов), а также database и analytics.
 * Тестирование негативных сценариев: отмена подписок, превышение лимитов, дубликаты платежей, пустой FTS-поиск.
## 🚀 Установка и запуск
 1. Клонируйте репозиторий:
```bash
git clone https://github.com/radfed6-bit/YurIIst.git
cd YurIIst

```
 2. Создайте виртуальное окружение и установите зависимости:
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

```
 3. Настройте переменные окружения:
   Скопируйте .env.example в .env и заполните ваши токены (API ключи Telegram и DeepSeek, а также ADMIN_TELEGRAM_ID).
 4. Запустите бота:
```bash
PYTHONPATH=. .venv/bin/python -m src.bot.main

```
Для запуска тестов используйте команду:
```bash
PYTHONPATH=. .venv/bin/python -m pytest tests/ -v

```
